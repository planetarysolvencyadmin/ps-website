# Brand originals

The logo files as supplied by the design agency, kept for reference. This folder starts with an underscore, so Jekyll does not publish it.

| File | What it is |
|---|---|
| `originals/PS_logo_colour_5.svg` | The vector master (colour, horizontal). |
| `originals/PS_logo_colour_raster_1.jpg`, `PS_logo_colour_raster_2.webp` | Raster versions of the same logo, as supplied. |

The site uses a copy of the SVG at `assets/images/logo.svg` (header) and a 64 px crop of the circular mark as `assets/images/favicon.png`. `assets/images/logo.png` is the previous raster logo and is no longer used.
